# LegalVC-OPC

> **研究驱动的投资 OPC** · Research-driven Investment OPC  
> **Investing in Legal Experience.**

LegalVC-OPC 是法务VC的运行实例，以**法律专业经验为核心投资对象**。围绕法律经验在 LLM 与 Agent 时代的识别、结构化、资产化、产品化与商业化，开展行业研究、机会发现、投资分析、资源配置与项目实践。

## 投资主题

**投资法律经验：推动具有明确来源、权利边界与使用条件的法律专业经验，转化为可复用的知识资产、产品、Agent、专业服务和商业价值。**

法律经验包括法律知识、案例与项目经验、专业判断、实务流程、行业 know-how，以及解决客户问题和提供专业服务的能力。

重点研究：

- **经验资产化**：经验如何被识别、结构化、授权、管理、复用与持续更新。
- **法律产品与 Agent**：LLM、Agent 和专业工作流如何承载、调用与校验法律经验，并满足质量、可靠性、安全和成本要求。
- **经验驱动的法律服务**：如何形成可验证客户价值、可持续交付和清晰商业模式。
- **创业与投资机会**：识别和评估能够把法律经验转化为产品、服务和商业价值的团队、企业与项目。

市场、客户、技术、产品、服务和商业模式研究，均服务于判断法律经验的价值及其转化机会，不改变法律经验这一核心投资对象。

## OPC 运行方式

LegalVC-OPC 以人类组织者为责任核心，使用 Agent 承担可委派任务，并按项目连接外部专业网络。

- **Founder / Human Organizer**：确定研究方向与投资论点，负责资源配置、关键关系、决策和最终责任。
- **Agent Team**：辅助行业研究、情报跟踪、机会分析、项目线索管理、研究编辑及项目支持。
- **External Network**：按项目连接法律专家、技术团队、专业贡献者、合作伙伴及资本资源方，并明确各方投入、权限、贡献、权益与责任。

Agent 是受授权的工具与执行系统，不具有独立法律人格。投资决策、专业判断、合同义务、数据使用和法律责任由适格的人或法律主体承担。

## 工作闭环

**Observe → Research → Discover → Evaluate → Allocate → Build & Learn**

观察法律服务市场、技术和监管变化；研究法律经验及其应用场景；发现团队、产品和项目；评估需求、技术、商业模式与风险；配置资金、专业经验、技术或其他资源；通过投资、共创或孵化验证结果，并将实践反馈到后续研究。

## 研究与执行原则

- 优先使用可追溯的一手证据，区分事实、外部主张、研究假设和分析判断。
- 记录来源、关键假设、反证、未知项和结论边界。
- 核实法律经验及相关数据的来源、权属、保密义务、授权范围和知识产权。
- 保护客户资料、个人信息、商业秘密及第三方权利。
- 明确项目参与者的投入、权限、贡献、权益、责任与利益冲突。
- 受监管的投资及金融活动，须依据实际主体、业务结构、司法辖区和适用要求开展。
