01 / OPC 与 LegalOPC

从新型生产组织，
到法律专业供给侧。

OPC 是 LLM 时代的新型生产组织形态；法务 VC OPC 是围绕这一形态展开的实践实验；LegalOPC 则是法律供给侧的专业生产单元。三个概念相互关联，但处于不同层级。

RESEARCH DIRECTION 01 · ORGANIZATION✳

OPC：LLM 时代的新型生产组织

OPC 以创始人／一个人与一组 Agent 协作为基本单元，实验 LLM 如何改变知识生产、专业分工与组织协作。它关注的是生产组织本身；Agent 是生产参与者与能力组成，而不是 OPC 的定位本身。

一人 + Agent 组知识生产专业分工组织协作

核心问题：一个人能否与一组 Agent 形成稳定协作，持续完成过去需要多人分工的复合型工作？这种协作将如何改变生产单元与组织边界？

RESEARCH DIRECTION 02 · LEGAL SUPPLY◈

LegalOPC：法律专业生产单元

LegalOPC 是法律供给侧的专业生产单元，由专业人士与一组 Agent 协作，把法律知识、专业判断、工作流程与交付成果组织为可持续运行的专业生产能力。

法律供给侧人机协作可说明可验证 · 可积累

核心问题：如何让人和 Agent 的协作过程、专业判断与交付结果可说明、可验证、可积累，并形成新的法律专业供给能力？

02 / 长期研究脉络

从创造力、产权与组织制度，重新思考 LLM 时代的生产力与组织形态。

法务 VC 长期关注创造力、生产力、知识与产权、劳动与资本、组织与企业，以及制度如何回应技术变迁。LLM 与 Agent 带来的能力变化，进一步打开了关于知识生产、专业分工和组织协作的新问题空间。

2015 年，法务 VC 开始围绕创业企业探索 4X4 股权与权利配置；2018 年，相关实践进一步发展为 4C 动态股权与人力资本化探索。进入 LLM 时代，Agent 带来的生产能力变化提出了新的问题：生产单元如何形成，人与 Agent 如何分工，组织如何协作，劳动、资本与产权关系如何变化。OPC 是面向这一新问题空间的独立实验，并非 4C 产品线的自然延伸。

创造力技术如何扩展人的创造能力，并提升知识生产力。
产权知识、数据与成果的产权如何界定，贡献如何识别。
组织制度人、Agent、劳动与资本如何形成新的协作关系。
财富与分配生产单元、组织边界与企业形态将如何演化。

“让世界更有创造力”是法务 VC 延续至今的品牌主张。2015 年，法务 VC 围绕创业企业开展 4X4 股权与权利配置探索；2018 年，相关实践发展为 4C 动态股权与人力资本化探索。LLM 时代，Agent 带来的生产能力变化打开了新的问题空间，法务 VC OPC 围绕新型生产组织展开实验。阅读 2018 年采访 ↗

法务 VC OPC 研究并验证一个人如何与一组 Agent 协作形成持续生产能力。商业化法律服务、订阅或产品可能成为实验结果，但不是 OPC 的定义。LegalOPC 是法律供给侧的专业生产单元；企业 AI 法务部是需求侧的应用场景。分田 Labs 等相关商业化实践独立运行，具体业务、资产与责任由相应主体承接。
