## 6. Clean-room alternative

If proposed material cannot be used:
- Can the task be researched from public sources?
- Can rules be independently created without consulting restricted material?
- Can synthetic examples cover the test need?
- What evidence establishes clean-room separation?
- Which source materials remain excluded?

A clean-room path is not a way to disguise copying or use of confidential know-how. It must be genuinely independent and reviewed.
