# LegalVC-OS Templates

Use these templates to create consistent, reviewable project records. Copy a template into the relevant project working folder or link the completed record from the project README.

| Template | Purpose | Used at |
|---|---|---|
| 01_opportunity_record.md | Capture a discovered professional experience and task | L0 |
| 02_value_and_demand_assessment.md | Assess experience value, customer problem and AI-native fit | L2 |
| 03_experience_profile.md | Reconstruct the expert's inputs, judgments, actions and boundaries | L1 |
| 04_rights_and_provenance_matrix.md | Track source, authority, permissions and use restrictions | L3 |
| 05_product_evaluation_record.md | Evaluate an AI-native product against defined tasks and risk | L4–L5 |
| 06_investment_memo_and_gate_decision.md | Record capital, rights, return and stage decisions | L6 |
| 07_pilot_report.md | Record customer usage, payment, quality and learning | L5 |
| 08_experience_asset_spec.md | Specify each structured experience asset and its lifecycle | L4 onward |

## Completion rules

- Keep one stable Project ID across all records.
- Keep a separate Asset ID for every experience asset.
- Label facts, party claims, hypotheses, inferences and results.
- Record links to source evidence and Rights Matrix.
- Do not place client-identifying or confidential content into this repository.
- Update versions rather than silently overwriting material professional rules.
